- [x] **v1.3.0 — rebuilt to the owner's sheet, one calculator, self-building bible** · Root cause of the failed rebuild found: Google caps a tab name at 31 characters, and the two "Calculation Step Look up Dough Use for …" names truncate to the SAME 31, so the second tab silently became `Sheet2` and every write to it vanished. Names are now short and distinct, `makeTab()` throws if Google returns a different name than asked for, and a test asserts every name fits. Sheet rebuilt to `Doughalulator.xlsx` exactly — 13 tabs, `Sic (balls)` with no separate Sic Trays column, no Boli on the EON count, bible mirrors with headings on row 1. The app is the only calculator; the sole exception is the new-bible fit, which needs the whole recorded history: the app appends each finished night (date, total sales, the day's whole use per size) to `New Bieblerb`/`New Peach Bieblerb` and the script refits the suggested column after every EON save. `writeBibles` no longer trusts its remembered hash once the mirrors are empty (that memory outlived a wipe and left the bible pages blank). Nights whose end-of-night sales fall below the 2 PM figure write a blank PM-takings cell rather than a negative, and teach the bible nothing — matching the owner's own `NA()` formulas. 36 nights imported and verified, 2026-05-13 → 2026-08-06. 159 tests.

- [x] **v1.4.0 — no keys** · At the owner's explicit request (twice affirmed) the shared secret is gone from both scripts and the app: Settings now holds one web address per notebook and nothing else. Because a key was the only thing standing between the open internet and a delete-everything command, the `wipe`/`retire` actions were removed from `doPost` entirely — erasing is now a guarded **Erase all data** menu item inside each spreadsheet, where being signed in is the protection. A test asserts both scripts refuse those types over HTTP. The /exec addresses should be treated as semi-public from here.
